# Chrome Web Store assets

Upload the screenshots in this order:

1. `screenshot-calculator.png` — completed calculator inputs
2. `screenshot-result.png` — calculated cost-per-use result
3. `screenshot-compare.png` — three-product comparison
4. `screenshot-history.png` — local calculation history
5. `screenshot-options.png` — settings and saved-record management

Promotional assets:

- `promo-tile-small.png` — required 440x280 tile
- `promo-tile-marquee.png` — optional 1400x560 marquee

The screenshots and promotional tiles are opaque, 24-bit PNG files in the dimensions required by the Chrome Web Store.
