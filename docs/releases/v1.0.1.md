# Cost Per Use v1.0.1

Version 1.0.1 is a multilingual design and privacy-focused update for the Chrome extension.

## Highlights

- Redesigned calculator, result, comparison, history, and settings interfaces.
- Added complete interface support for 10 languages with English fallback.
- Added automatic browser-language selection and right-to-left Arabic layout.
- Added improved local history, comparison, language, and theme experiences.
- Replaced the Store media set with five production screenshots and refreshed promotional tiles.

## Privacy and permissions

- Removed the broad always-on content-script declaration.
- Optional page auto-fill runs only when the user opens the extension and has enabled the feature.
- Calculations, preferences, comparisons, and history remain on the user's device.
- No analytics, advertising, accounts, remote code, or cloud synchronization were added.
