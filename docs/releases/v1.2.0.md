# Cost Per Use v1.2.0

## Broader product autofill support

- Read Schema.org Product JSON-LD, ProductGroup variants, and standard product metadata on supported e-commerce sites (such as Shopify storefronts and modern online retailers).
- Automatically match product variants to the current page URL without sending data to external servers.
- Preserve already-entered values when autofill extracts partial data.
- Provide clear feedback when a page title is found without a definitive single-item price.

## Search and store listing improvements

- Updated keyword-optimized store summaries highlighting cost-per-wear calculation and impulse-buy prevention.
- Added repository topics and linked the live interactive web demo directly.
- Refined localized store listings for English and Turkish.

## Privacy and permissions

Existing saved history and settings are completely retained. Permissions remain unchanged: `storage`, `scripting`, and `activeTab`. No analytics, accounts, cloud sync, or external tracking were added. All product data is parsed locally in the browser and never leaves your machine.

## Release verification

Run `npm run release:check` to execute the full test pipeline:
- 226 unit and localization tests.
- UI scenario and cost target tests across 10 languages and 2 themes.
- Product reader test suite with 11 browser fixtures.
- Packaged extension validation in an isolated Chromium profile with real `activeTab` autofill.
- Store asset verification and byte-for-byte archive validation.
