# Cost Per Use v1.0.2

Version 1.0.2 fixes the real Chrome popup size and introduces a localized update notice.

## Highlights

- The popup now opens at a stable Chrome-safe 400x600 size.
- Calculator fields, presets, currency selection, results, comparison cards, and actions no longer clip horizontally.
- Header, tabs, scrollable content, and the support footer stay inside the popup viewport.
- A one-time "What's new" dialog appears after each version update.
- The dialog links to full release notes and voluntary Patreon support.
- Update copy is available in all 10 supported interface languages, including Arabic RTL.

## Update-notice behavior

The notice appears the first time a user opens the popup after installing a new version. Dismissing it stores only the version number in local extension storage, so it does not appear again until another version is installed.

Chrome does not allow an extension to force its toolbar popup open immediately after a background update. Showing the notice on the user's next normal popup open provides the update information without interrupting browsing.

## Privacy

- No new user data is collected or transmitted.
- The last-seen version marker remains in `chrome.storage.local`.
- Calculations, preferences, comparisons, and history remain on the user's device.
- No analytics, advertising, accounts, remote code, or cloud synchronization were added.
