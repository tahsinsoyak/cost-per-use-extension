# Privacy practices answers

## Single purpose

Help users evaluate and compare purchases by calculating the expected cost per use of products.

## Data disclosures

Disclose these categories because Chrome requires disclosure even when data is processed only on the user's device:

- Website content: optional auto-fill reads the active page's product title, displayed price, and currency hint.
- Web history or browsing activity: the active tab URL hostname is read transiently to identify a supported shopping site and to avoid restricted browser pages. URLs are not retained as browsing history.
- Form data or user-provided content, if shown in the dashboard: calculator inputs, settings, comparisons, and saved calculations are stored locally.

For every selected category, state that data is used only for the extension's user-facing calculation and auto-fill features. It is not transmitted, sold, used for advertising, or accessed by humans.

## Certifications

Certify all applicable Limited Use statements. The extension:

- Does not sell or transfer user data to third parties.
- Does not use or transfer user data for purposes unrelated to its single purpose.
- Does not use or transfer user data for creditworthiness or lending.
- Does not use user data for personalized advertising.
- Does not allow humans to read user data.
