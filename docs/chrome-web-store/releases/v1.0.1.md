# Chrome Web Store update 1.0.1

Use this page while updating the existing Chrome Web Store item from `1.0.0` to `1.0.1`.

## Package

- Version: `1.0.1`
- Upload file: `cost-per-use-extension.zip`
- Dashboard action: open the existing item, select **Package**, then **Upload new package**.
- Do not create a second Store item. Uploading the package to the existing item preserves its item ID, users, reviews, and visibility.

## What's new text

Use this text wherever the dashboard offers release notes or reviewer context:

> Version 1.0.1 introduces a redesigned calculator and settings experience, support for 10 interface languages, improved product comparison and local history views, and refreshed Chrome Web Store assets. Optional shopping-page auto-fill now runs only when the user opens the extension and has enabled the feature. All calculations and saved data remain local to the user's browser.

## Listing changes

- Keep the title and summary supplied by the localized package.
- Use `Shopping` as the category.
- Replace the global screenshots with the five files in `store-assets`, in the documented order.
- Upload the refreshed small and marquee promotional tiles.
- Paste the detailed description for each supported language from `../listings/`.
- Keep mature content set to `No` and item support set to `On`.

## Privacy and permissions

- Single purpose: `Help users evaluate and compare purchases by calculating the expected cost per use of products.`
- Select **No, I am not using remote code**.
- Paste the `storage`, `activeTab`, and `scripting` explanations from `../permission-justifications.md`.
- Review the locally processed data categories and certifications in `../privacy-practices.md`.
- Privacy policy URL: `https://github.com/tahsinsoyak/cost-per-use-extension/blob/main/docs/privacy-policy.md`

## Distribution and review

- Keep **Free of charge** unless paid features are added later.
- Keep the existing visibility and region settings unless you intentionally want to change distribution.
- No credentials are required. In **Additional instructions**, enter:

> No login, account, payment, or special setup is required. Open the toolbar popup, enter a product price, ownership period, and expected usage, then select Calculate. Comparison, saved history, language settings, import/export, and optional auto-fill can be tested without credentials. Auto-fill is disabled by default and can be enabled in Settings before opening the extension on a shopping product page.

- Submit the update for review after every dashboard tab shows as complete.
- For a controlled launch, turn off automatic publishing in the confirmation dialog. After approval, publish the staged update within 30 days.
