# Chrome Web Store update 1.0.2

Use this page to upload the corrected package before submitting the existing Store item for review.

## Package

- Version: `1.0.2`
- Upload file: `cost-per-use-extension.zip`
- Dashboard action: open the existing item, select **Package**, then **Upload new package**.
- Do not create a second Store item.

If version `1.0.1` is currently a draft, uploading `1.0.2` replaces that draft. Since the item has not been submitted for review, only the corrected `1.0.2` package needs to be reviewed.

## What's new text

> Version 1.0.2 fixes the Chrome popup so the complete calculator opens at a reliable full size without clipped controls. It also adds a localized, one-time What's New screen shown on the first popup open after each update, with links to release notes and voluntary support. All calculations and saved data remain local to the user's browser.

## Listing and privacy

- Keep the existing localized titles, summaries, descriptions, screenshots, and promotional assets.
- Keep the category set to `Shopping`.
- Keep **No remote code** selected.
- Keep the existing privacy disclosures and three Limited Use certifications.
- Privacy policy: `https://github.com/tahsinsoyak/cost-per-use-extension/blob/main/docs/privacy-policy.md`

The update dialog stores only the last version seen in `chrome.storage.local`; it does not add a new collected-data category.

## Reviewer instructions

Leave username and password blank. Use:

> No login, account, payment, or special setup is required. On first open, dismiss the localized What's New screen by selecting Start calculating. Enter a product price, ownership period, and expected usage, then select Calculate. Verify that all popup controls fit without horizontal clipping. Comparison, saved history, language settings, import/export, and optional auto-fill can be tested without credentials.
