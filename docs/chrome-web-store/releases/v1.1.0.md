## What's new

> Compare your expected cost per use with half as much use, and set a personal target to see how many uses you need. Usage labels now describe estimated use without judging affordability. This update also improves installment validation, imported calculations, and restoration of saved purchases. All new features are translated into ten languages. Your calculations and settings remain local to your browser.

## Reviewer instructions

No account, login, or payment is required. On first open, dismiss the What's New dialog. Enter a price of 200, a duration of one year, and five uses per week, then calculate. The result shows expected cost per use and half as much use. Enter a target of 0.50 to see 400 total uses needed. Save the calculation, add it to comparison, and verify it appears in history. Test JSON export/import in settings. Optional autofill can be enabled in settings and tested by opening the extension on a product page. Arabic and the other nine languages are available in settings.

## Before submitting

1. Run `npm run release:check` and use the resulting ZIP, not a previous archive.
2. Review the unpacked `dist/` extension in Chrome, including a product page you use regularly.
3. Confirm the listing previews and dashboard have no missing required fields.
4. Submit the existing item for review. Choose automatic publication after approval or staged publication according to your preference.

GitHub Pages publishing updates the website only. Uploading this ZIP and submitting it to Chrome Web Store are separate steps; neither is performed by the website workflow.
