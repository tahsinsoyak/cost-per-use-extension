# 简体中文商店详情

## 标题

`单次使用成本：智能购物与性价比计算器`

## 摘要

`购买前计算商品每次使用的真实成本与每次穿搭成本。并排比较商品，拒绝冲动消费，助您精明省钱。`

## 详细说明

告别冲动消费，开启精明购物。“单次使用成本”（Cost Per Use）是一款专为 Chrome 打造的智能购物、每次穿搭成本（Cost Per Wear）与性价比计算器。

价格标签并不能反映商品的真实价值。一双穿了 3 次的 1200 元鞋子，每次穿着成本高达 400 元；而一件穿了 200 天的 2000 元冬装大衣，每天成本仅需 10 元。本扩展程序帮助您在付款前算清每一笔消费的真实价值。

无论您是在 Amazon、eBay、Shopify 独立站还是日常电商平台购物，都能在几秒钟内获得清晰的消费决策参考。

核心功能：

一键自动读取商品信息
在浏览 Amazon、eBay、Shopify 商店及主流购物网站时，自动识别商品名称、价格和货币，无需手动输入。

个人目标成本测算
设定您理想的每次使用目标成本（例如每次 5 元），立即查看需要最少使用多少次才能值回票价。

最多 3 件商品并排对比
同时对比最多 3 款候选商品，直观找出性价比最高的选择。

“使用减半”现实场景模拟
自动对比预计使用次数与实际仅使用一半次数下的单次成本，帮您避免买后闲置和消费后悔。

净成本与分期付款计算
支持计入二手转售预估价值、日常维护保养费用以及分期付款总金额，算出真正的净支出。

工作时间等值换算
根据您的时薪，将商品价格直接换算为您需要付出的工作小时数。

本地历史记录与 JSON 备份
在本地保存过往计算记录，支持随时导出为 JSON 文件备份或重新导入。

隐私至上与纯本地存储：
- 无需注册账号或登录
- 零统计分析、零追踪器、零广告
- 无云端数据库，所有数据严格保存在您的本地浏览器中
