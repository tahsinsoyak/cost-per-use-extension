# 简体中文商店详情

## 标题

`单次使用成本`

## 摘要

`购买前计算商品每次使用的实际成本。`

## 详细说明

“单次使用成本”通过估算商品每次预计使用的实际花费，帮助您更合理地评估购买决定。

输入商品价格、预计持有期限和使用频率，即可计算单次使用成本。为了获得更完整的估算，您还可以加入预计转售价值、维护费用、分期次数和付款总额。输入时薪后，还可以查看购买商品所需工作时间的等值结果。

您可以并排比较最多三件商品，将计算结果保存在本地，并以JSON格式导入或导出历史记录。启用可选的自动填充功能并打开扩展程序后，它可以从当前购物页面读取商品名称、显示价格和货币。

主要功能：

- 计算单次使用成本和净成本
- 计入转售价值和维护费用
- 计算分期付款和付款总额
- 可选的工作时间等值换算
- 并排比较最多三件商品
- 支持JSON导入和导出的本地计算历史
- 可选地从当前页面填充商品名称、价格和货币
- 支持USD、TRY、EUR、GBP和自定义货币
- 浅色和深色主题
- 支持10种语言的界面

我们重视隐私。页面信息、设置、比较内容和计算结果都在Chrome中本地处理并保存。“单次使用成本”无需账户，不包含分析、广告、跟踪器或云服务。用户数据不会被出售或与第三方共享。

“单次使用成本”完全免费并且开源。支持页面中提供自愿使用的Patreon链接，但它不会解锁任何功能，也不是使用扩展程序的必要条件。
