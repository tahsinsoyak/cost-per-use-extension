# صفحة المتجر باللغة العربية

## العنوان

`تكلفة الاستخدام`

## الملخص

`احسب التكلفة الحقيقية لكل استخدام قبل الشراء.`

## الوصف التفصيلي

يساعدك «تكلفة الاستخدام» على تقييم مشترياتك من خلال تقدير التكلفة الفعلية لكل مرة تتوقع فيها استخدام المنتج.

أدخل سعر المنتج ومدة امتلاكه المتوقعة ومعدل استخدامه لحساب التكلفة لكل استخدام. وللحصول على تقدير أكثر شمولًا، يمكنك إضافة قيمة إعادة البيع وتكاليف الصيانة وعدد الأقساط والمبلغ الإجمالي المدفوع. ويمكنك أيضًا تحويل تكلفة الشراء إلى ما يعادلها من وقت العمل باستخدام أجرك بالساعة.

قارن ما يصل إلى ثلاثة منتجات جنبًا إلى جنب، واحفظ الحسابات محليًا، واستورد سجلّك أو صدّره بتنسيق JSON. يمكن لميزة الملء التلقائي الاختيارية قراءة اسم المنتج والسعر المعروض والعملة من صفحة التسوق النشطة بعد تفعيل الميزة وفتح الإضافة.

الميزات الرئيسية:

- حساب التكلفة لكل استخدام والتكلفة الصافية
- احتساب قيمة إعادة البيع وتكاليف الصيانة
- حساب الأقساط وإجمالي المبلغ المدفوع
- عرض اختياري للتكلفة بما يعادل وقت العمل
- مقارنة ما يصل إلى ثلاثة منتجات
- سجل محلي مع استيراد JSON وتصديره
- ملء اختياري لاسم المنتج والسعر والعملة من الصفحة النشطة
- دعم USD وTRY وEUR وGBP والعملات المخصصة
- مظهر فاتح ومظهر داكن
- واجهة متاحة بعشر لغات

الخصوصية أولًا. تتم معالجة معلومات الصفحات والإعدادات والمقارنات والحسابات وتخزينها محليًا داخل Chrome. لا يتطلب «تكلفة الاستخدام» إنشاء حساب، ولا يتضمن تحليلات أو إعلانات أو أدوات تتبع أو خدمات سحابية. لا تُباع بيانات المستخدمين ولا تُشارك مع جهات خارجية.

«تكلفة الاستخدام» مجاني ومفتوح المصدر. يتوفر رابط اختياري إلى Patreon في قسم الدعم، لكنه لا يفتح أي ميزات إضافية ولا يلزم لاستخدام الإضافة.
