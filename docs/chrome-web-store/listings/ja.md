# 日本語のストア掲載情報

## タイトル

`1回あたりのコスト`

## 概要

`購入前に商品の1回あたりの実質コストを計算します。`

## 詳細な説明

「1回あたりのコスト」は、商品を使用するたびに実際いくらかかるかを見積もり、購入判断をサポートする拡張機能です。

商品価格、予定している所有期間、使用頻度を入力すると、1回あたりのコストを計算できます。より詳しく見積もる場合は、再販価格、メンテナンス費用、分割回数、支払総額も含められます。時給を設定すれば、購入費用を労働時間に換算して確認することもできます。

最大3つの商品を並べて比較し、計算結果をローカルに保存できます。履歴はJSON形式で読み込み、書き出しが可能です。任意の自動入力機能を有効にして拡張機能を開くと、アクティブなショッピングページから商品名、表示価格、通貨を読み取ることができます。

主な機能：

- 1回あたりのコストと実質コストの計算
- 再販価格とメンテナンス費用の調整
- 分割払いと支払総額の計算
- 労働時間への任意換算
- 最大3商品の比較
- JSONの読み込みと書き出しに対応したローカル履歴
- アクティブなページからの商品名、価格、通貨の任意自動入力
- USD、TRY、EUR、GBP、カスタム通貨
- ライトテーマとダークテーマ
- 10言語に対応したインターフェース

プライバシーを最優先にしています。ページ情報、設定、比較、計算結果はChrome内でローカルに処理、保存されます。アカウントは不要で、アクセス解析、広告、トラッカー、クラウドサービスは使用しません。ユーザーデータを販売したり、第三者と共有したりすることもありません。

「1回あたりのコスト」は無料のオープンソース拡張機能です。サポート画面には任意のPatreonリンクがありますが、機能の解除には関係なく、拡張機能の利用に必要ありません。
