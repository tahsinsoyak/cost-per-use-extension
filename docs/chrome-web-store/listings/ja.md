# 日本語のストア掲載情報

## タイトル

`1回あたりのコスト：スマート買い物＆コスパ計算ツール`

## 概要

`購入前に1回あたりの実質コストや着用単価を計算。最大3商品を比較し、衝動買いを防いで賢く節約できる買い物サポート拡張機能です。`

## 詳細な説明

衝動買いを減らし、もっと賢く買い物をしましょう。「1回あたりのコスト」は、購入前に商品の実質的な使用単価（コスト・パー・ユース／着用単価）とコストパフォーマンスを計算できるChrome向けスマート買い物計算ツールです。

値札だけでは本当の価値はわかりません。3回しか履かない18,000円の靴は1回あたり6,000円かかりますが、200日間着る30,000円の冬用コートは1回あたりわずか150円です。本拡張機能を使えば、購入ボタンを押す前にその買い物が本当に価値ある投資かどうかを数秒で判断できます。

Amazon、eBay、Shopifyストア、その他のオンラインショップでの買い物を強力にサポートします。

主な機能：

ワンクリック商品自動入力
Amazon、eBay、Shopifyストアなどの対応ECサイトを閲覧中、商品名・価格・通貨を自動的に読み取ります。手入力の手間がかかりません。

目標コスト設定
1回あたりの目標コスト（例：1回50円など）を入力すると、元を取るために必要な最低使用回数が一目でわかります。

最大3商品の並べて比較
最大3つの候補商品を同時に比較し、どれが最もコストパフォーマンスに優れているかを簡単に判断できます。

「もし半分しか使わなかったら」シナリオ比較
予定の半分の回数しか使わなかった場合の単価を自動表示し、買った後の後悔やタンスの肥やしを防ぎます。

実質コスト＆分割払い計算
売却予想価格（リセールバリュー）、維持・メンテナンス費用、分割払いの支払総額を考慮したリアルな実質負担額を算出します。

労働時間換算
時給を設定することで、その商品を買うために何時間働く必要があるかを換算して表示します。

ローカル履歴保存＆JSON出力
過去の計算履歴をブラウザ内に保存し、JSON形式でのバックアップ書き出しや読み込みに対応しています。

プライバシー最優先＆完全ローカル保存：
- アカウント作成、会員登録、ログインは一切不要
- アクセス解析、トラッカー、広告はゼロ
- クラウド送信なし。すべてのデータはあなたのパソコン内にのみ保存されます
