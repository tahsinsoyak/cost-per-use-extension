# Localized store listings

The extension package supplies the localized title and summary from `public/_locales`. Chrome Web Store does not import the detailed descriptions below from the package.

In the Developer Dashboard, open **Store listing**, select each language, and paste the matching **Detailed description**. Keep the category set to **Shopping** and use the global screenshots unless localized screenshots are available.
