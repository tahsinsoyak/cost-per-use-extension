# Privacy Policy for Cost Per Use

Last updated: July 13, 2026

Cost Per Use is a local-first Chrome extension for estimating and comparing the expected cost per use of products. This policy explains the data the extension handles and how it is used.

## Data handled by the extension

The extension can handle:

- Calculator inputs, including product names, prices, usage estimates, ownership periods, resale values, maintenance costs, and optional wage values.
- Settings, saved calculations, and product comparisons.
- When optional auto-fill is enabled, the active page's product title, displayed price, currency hint, and URL hostname.

Auto-fill is disabled by default. When enabled, it runs only after the user opens the extension on an active page. It does not continuously monitor browsing.

## How data is used and stored

Data is used only to provide the calculator, comparison, history, import/export, and optional active-page auto-fill features.

All handled data is processed on the user's device. Settings and saved data are stored in `chrome.storage.local`. Cost Per Use has no developer-operated server, analytics, advertising SDK, account system, or cloud synchronization.

## Data sharing

Cost Per Use does not transmit, sell, rent, or share user data with the developer or any third party. The developer cannot access data stored by the extension.

The interface contains a voluntary link to Patreon. Patreon is opened only after the user clicks the link. No extension data is sent to Patreon.

## User choices and deletion

Users can keep auto-fill disabled and enter all values manually. Saved calculations can be deleted individually or cleared from the options page. Removing the extension also removes its local extension storage according to Chrome's behavior. Users can export or import calculation data as a local JSON file.

## Chrome Web Store Limited Use disclosure

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

Material changes to these practices will be disclosed in the extension interface and this policy before new data handling begins.
